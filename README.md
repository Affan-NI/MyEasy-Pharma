  # 💊 MyEasy Pharma – AI Native Healthcare Platform

MyEasy Pharma is an **AI-powered healthcare web platform** designed to make healthcare services more accessible and intelligent.
The platform provides pharmaceutical information, disease prediction tools, and a modern healthcare interface using AI-driven features.

The project focuses on building a **modern healthcare SaaS platform** that integrates medicine information, intelligent disease prediction, and healthcare assistance through a responsive web application.

🌐 Live Demo:
https://myeasypharma.vercel.app

---

# 🚀 Features

🧠 **AI Disease Prediction**
Predict possible diseases based on symptoms using an intelligent model.

💊 **Medicine & Healthcare Platform**
Provides a modern interface for accessing pharmaceutical and healthcare-related information.

📱 **Responsive UI**
Fully responsive design that works on mobile, tablet, and desktop devices.

⚡ **Fast Frontend Application**
Built using modern JavaScript frameworks for high performance.

🧩 **Modular Project Structure**
Organized frontend and AI modules for scalability.

🌐 **Cloud Deployment**
Deployed using Vercel for fast global delivery.

# ⚙️ Installation & Setup

Clone the repository

```
git clone https://github.com/Affan-NI/MyEasy-Pharma.git
```

Go to the project directory

```
cd MyEasy-Pharma
```

Install dependencies

```
npm install
```

Run the development server

```
npm run dev
```
